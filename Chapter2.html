2.1 Number system and conversion

A number system defines a set of values used to represent quantity. In digital computers, different number systems are used for different purposes. The most common are decimal, binary, octal, and hexadecimal.

2.1.1 Decimal, Binary, Octal, Hexadecimal Number System & conversion

Decimal (Base-10): Uses digits 0 to 9. It is the standard system for human counting. Each position represents a power of 10.

Binary (Base-2): Uses only two digits, 0 and 1. It is the fundamental language of computers, where 0 represents OFF and 1 represents ON. Each position represents a power of 2.

Octal (Base-8): Uses digits 0 to 7. Each position represents a power of 8. It is often used as a shorthand for binary.

Hexadecimal (Base-16): Uses digits 0 to 9 and letters A to F (where A=10, B=11, C=12, D=13, E=14, F=15). Each position represents a power of 16. It is widely used in computing to represent memory addresses and color codes.

Conversion methods:

  • Decimal to Binary: Divide the decimal number by 2 repeatedly and record the remainders (from last to first).
  • Binary to Decimal: Multiply each binary digit by its corresponding power of 2 and sum the results.
  • Decimal to Octal / Hexadecimal: Divide by 8 or 16 repeatedly, recording remainders.
  • Octal / Hexadecimal to Binary: Convert each digit into its 3-bit (octal) or 4-bit (hexadecimal) binary equivalent.
  • Binary to Octal / Hexadecimal: Group binary digits into sets of 3 (from right, for octal) or 4 (from right, for hexadecimal) and convert each group to its equivalent digit.
2.1.2 Calculation in binary addition, subtraction

Binary Addition: Similar to decimal addition but with only two digits. The rules are:

  • 0 + 0 = 0 (carry 0)
  • 0 + 1 = 1 (carry 0)
  • 1 + 0 = 1 (carry 0)
  • 1 + 1 = 0 (carry 1 to the next higher bit)

Example: 1011 (11) + 0110 (6) = 10001 (17).

Binary Subtraction: Can be done directly using borrow method (like decimal), but computers typically use complement methods (described in 2.1.3) for efficiency. Direct subtraction rules:

  • 0 - 0 = 0
  • 1 - 0 = 1
  • 1 - 1 = 0
  • 0 - 1 = 1 (borrow 1 from the next higher bit)
2.1.3 One's and Two's complement methods of binary subtraction

Computers use complement methods to perform subtraction using addition circuitry, which is simpler and faster.

  • One's Complement: To get the one's complement of a binary number, simply invert all bits (change 0 to 1 and 1 to 0). To subtract using one's complement: take the one's complement of the subtrahend, add it to the minuend, and if there is a carry from the most significant bit, add that carry back to the result (end-around carry).
  • Two's Complement: To get the two's complement, add 1 to the one's complement. To subtract, take the two's complement of the subtrahend and add it to the minuend. Any carry beyond the most significant bit is discarded. This is the standard method used in most modern computers because it handles signed numbers elegantly and avoids the end-around carry issue.
2.2 Logic Function and Boolean Algebra

Boolean algebra is a branch of mathematics that deals with variables that have only two values: true (1) or false (0). It is fundamental to digital logic circuit design.

2.2.1 Introduction to Boolean algebra

Boolean algebra was introduced by George Boole in 1854. It uses binary variables and logical operations (AND, OR, NOT) to perform mathematical logic. It is the basis for designing and analyzing digital circuits in computers.

2.2.2 Introduction to Boolean values, truth table, Boolean expression and Boolean function
  • Boolean Values: The only two possible values are 0 (false) and 1 (true).
  • Truth Table: A table that lists all possible combinations of input variables and the corresponding output of a logical expression.
  • Boolean Expression: A mathematical statement formed using Boolean variables and logical operators (e.g., A · B + C).
  • Boolean Function: A mapping from a set of input combinations to a single output value, typically represented by a Boolean expression or a truth table.
2.2.3 Logic Gates - AND, OR, NOT, NAND, NOR, XOR and XNOR - its definition, truth table, logic symbol, logic function

Logic gates are electronic circuits that implement basic Boolean operations.

  • AND Gate: Output is 1 only if all inputs are 1. Logic function: A · B. Truth table: 00→0, 01→0, 10→0, 11→1.
  • OR Gate: Output is 1 if at least one input is 1. Logic function: A + B. Truth table: 00→0, 01→1, 10→1, 11→1.
  • NOT Gate (Inverter): Output is the complement of the input. Logic function: A' (or ¬A). Truth table: 0→1, 1→0.
  • NAND Gate: Output is the complement of AND (NOT AND). Logic function: (A · B)'. Truth table: 00→1, 01→1, 10→1, 11→0.
  • NOR Gate: Output is the complement of OR (NOT OR). Logic function: (A + B)'. Truth table: 00→1, 01→0, 10→0, 11→0.
  • XOR Gate (Exclusive OR): Output is 1 if inputs are different. Logic function: A ⊕ B. Truth table: 00→0, 01→1, 10→1, 11→0.
  • XNOR Gate (Exclusive NOR): Output is 1 if inputs are same (complement of XOR). Logic function: (A ⊕ B)'. Truth table: 00→1, 01→0, 10→0, 11→1.

Each gate has a standard logic symbol (triangle, D-shape, etc.) used in circuit diagrams, along with its corresponding truth table and Boolean expression.

2.2.4 Laws of Boolean algebra - Boolean Identities, Complement Laws, Identity, Commutative, Associative and Distributive

These laws are used to simplify Boolean expressions.

  • Boolean Identities (Basic):
    • A · 0 = 0
    • A · 1 = A
    • A + 0 = A
    • A + 1 = 1
  • Complement Laws:
    • A · A' = 0
    • A + A' = 1
    • (A')' = A
  • Identity Law: A + 0 = A and A · 1 = A.
  • Commutative Law: A + B = B + A and A · B = B · A (order does not matter).
  • Associative Law: (A + B) + C = A + (B + C) and (A · B) · C = A · (B · C) (grouping does not matter).
  • Distributive Law: A · (B + C) = (A · B) + (A · C) and A + (B · C) = (A + B) · (A + C).
2.2.5 Statement and verification of Laws of Boolean algebra using truth table

All Boolean laws can be verified by constructing a truth table that lists all possible values of the variables and showing that both sides of the equation yield the same output for every combination.

For example, to verify the Distributive Law A · (B + C) = (A · B) + (A · C):

  • List all 8 possible combinations of A, B, C (000, 001, 010, 011, 100, 101, 110, 111).
  • Compute the left side (A · (B + C)) for each combination.
  • Compute the right side ((A · B) + (A · C)) for each combination.
  • Compare the results; if they match for all rows, the law is verified.

Similarly, the Commutative, Associative, and other laws can be verified using truth tables. This method provides a rigorous proof of each law's validity.
