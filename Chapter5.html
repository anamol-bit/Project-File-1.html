5.1 Programming Concept

Programming is the process of creating a set of instructions that tell a computer how to perform a task. It involves writing code in a programming language that the computer can understand and execute.

5.1.1 Introduction to programming languages

A programming language is a formal language consisting of a set of instructions that produce various kinds of output. It is used to communicate with computers and create software applications. Programming languages have their own syntax (rules) and semantics (meaning). Examples include C, C++, Java, Python, and JavaScript.

5.1.2 Low level, High level, 4 GL programming languages
  • Low-Level Languages: These are close to machine language and are hardware-dependent. They are difficult for humans to read and write but execute very fast.
    • Machine Language: The lowest level, consisting of binary code (0s and 1s) directly understood by the CPU.
    • Assembly Language: Uses mnemonics (like ADD, MOV) to represent machine instructions. Requires an assembler to convert to machine code.
  • High-Level Languages: These are closer to human languages and are easier to read, write, and maintain. They are machine-independent and require compilers or interpreters to translate into machine code. Examples: C, C++, Java, Python, JavaScript.
  • Fourth-Generation Languages (4GL): These are even more user-friendly and closer to natural language. They are designed for specific applications like database querying and report generation. Examples: SQL, MATLAB, SAS.
5.1.3 Compiler, Interpreter and Assembler
  • Compiler: A program that translates the entire source code of a high-level language into machine code (object code) in one go. It generates an executable file that can be run independently. Examples: GCC for C, javac for Java. It checks for syntax errors before execution.
  • Interpreter: A program that translates and executes high-level code line by line. It does not produce a separate executable file; it translates and executes simultaneously. If an error occurs, execution stops at that line. Examples: Python interpreter, JavaScript interpreter.
  • Assembler: A program that translates assembly language code into machine language. It converts mnemonics into binary instructions that the CPU can execute directly.
5.1.4 Syntax, Semantic and Runtime errors
  • Syntax Errors: Errors that occur when the code violates the grammatical rules of the programming language. These are caught by the compiler or interpreter. Example: missing semicolon, incorrect spelling of a keyword.
  • Semantic Errors: Errors that occur when the code is syntactically correct but does not make logical sense or produces unintended results. Example: using the wrong operator (addition instead of subtraction).
  • Runtime Errors: Errors that occur during program execution. These cause the program to crash or behave unexpectedly. Example: division by zero, accessing an array out of bounds, file not found.
5.1.5 Control structures: Sequence, Selection and Iteration

Control structures determine the flow of execution in a program. There are three fundamental types:

  • Sequence: Statements are executed in order, one after another, from top to bottom. This is the default flow of a program.
  • Selection (Decision Making): The program chooses which block of code to execute based on a condition. This includes if, if-else, if-else-if, and switch statements.
  • Iteration (Looping): A block of code is executed repeatedly as long as a condition remains true. This includes for, while, and do-while loops.
5.1.6 Program Design tools - Algorithm, Flowchart and Pseudocode

Before writing actual code, programmers use design tools to plan the logic of the program.

  • Algorithm: A step-by-step procedure or set of rules to solve a problem or accomplish a task. It is written in plain English or a structured format. Example: An algorithm to add two numbers: Step 1: Start, Step 2: Read A and B, Step 3: Calculate sum = A + B, Step 4: Display sum, Step 5: End.
  • Flowchart: A graphical representation of an algorithm using symbols like ovals (start/end), parallelograms (input/output), rectangles (processing), diamonds (decision), and arrows (flow direction).
  • Pseudocode: A simplified, human-readable version of code that uses plain language and programming-like constructs. It is not actual code but helps in planning the logic. Example: BEGIN, READ A, CALCULATE SUM = A + B, PRINT SUM, END.
5.1.7 Absolute binary, BCD, ASCII and Unicode
  • Absolute Binary: The direct binary representation of a number as stored in memory, often used in machine-level programming.
  • BCD (Binary Coded Decimal): A method of encoding decimal numbers where each decimal digit is represented by a 4-bit binary number. Example: 12 is represented as 0001 0010. Used in applications where decimal accuracy is important (financial systems).
  • ASCII (American Standard Code for Information Interchange): A character encoding standard that uses 7-bit or 8-bit codes to represent characters (letters, digits, symbols). Example: 'A' = 65, 'a' = 97, '0' = 48.
  • Unicode: A universal character encoding standard that supports almost all writing systems in the world. It uses up to 32 bits per character and can represent over 140,000 characters. Examples: UTF-8, UTF-16, UTF-32.
5.2 C Programming Language

C is a general-purpose, high-level programming language developed by Dennis Ritchie at Bell Labs in 1972. It is widely used for system programming, embedded systems, and application development. C is known for its efficiency, flexibility, and control over system resources.

5.2.1 Introduction and Features of C Language

C is a structured, procedural programming language. Its key features include:

  • Simplicity and Efficiency: C has a small set of keywords and is highly efficient in execution.
  • Portability: C programs can run on different platforms with minimal changes.
  • Rich Library: C provides a large set of built-in functions (header files).
  • Low-level Access: C allows direct memory manipulation using pointers.
  • Structured Language: C supports functions and control structures for modular programming.
  • Recursion: C supports recursive function calls.
5.2.2 Structure of C program

A typical C program has the following structure:

    #include <stdio.h>   // Preprocessor directive
    #include <conio.h>   // For getch() etc.

    void main() {        // Main function - program execution starts here
        // Variable declarations
        // Statements
        // Input/Output operations
        getch();        // To hold the screen (optional)
    }
5.2.3 C Preprocessor and Header Files

Preprocessor: It is a program that processes the source code before it is compiled. Preprocessor directives start with a # symbol. Examples: #include, #define, #ifdef.

Header Files: These are files with a .h extension that contain function declarations, macros, and type definitions. They are included in the program using the #include directive. Common header files:

  • stdio.h: Standard Input/Output (printf, scanf, getchar, putchar).
  • conio.h: Console Input/Output (getch, clrscr - not standard).
  • string.h: String handling functions (strlen, strcpy, strcat).
  • math.h: Mathematical functions (sqrt, pow, sin, cos).
  • stdlib.h: Standard library functions (malloc, free, atoi).
5.2.4 Character Set used in C

C uses the ASCII character set (or extended ASCII) to represent characters. It includes:

  • Alphabets: A-Z (uppercase), a-z (lowercase)
  • Digits: 0-9
  • Special Symbols: @, #, $, %, ^, &, *, (, ), {, }, [, ], <, >, etc.
  • White Spaces: Space, tab, newline, carriage return.
5.2.5 Use of Comments

Comments are used to explain the code and make it readable. They are ignored by the compiler. In C, there are two types:

  • Single-line comment: Starts with //. Example: // This is a comment.
  • Multi-line comment: Enclosed between /* and */. Example: /* This is a multi-line comment */
5.2.6 Identifiers, Keywords and Tokens
  • Identifiers: Names given to variables, functions, arrays, and other user-defined items. They must start with a letter or underscore and can contain letters, digits, and underscores. Example: age, _sum, total1.
  • Keywords: Reserved words in C that have a predefined meaning. They cannot be used as identifiers. Examples: int, float, char, if, else, for, while, return, void, main.
  • Tokens: The smallest individual units in a C program. Tokens include keywords, identifiers, constants, strings, operators, and separators (like semicolon, braces).
5.2.7 Basic Data Types in C

C has several basic data types that define the type of data a variable can store:

  • int: Stores integer values (whole numbers). Size: 2 or 4 bytes.
  • char: Stores a single character. Size: 1 byte.
  • float: Stores floating-point numbers (real numbers with decimal). Size: 4 bytes.
  • double: Stores double-precision floating-point numbers. Size: 8 bytes.
  • void: Represents no value. Used for functions that do not return anything.
5.2.8 Constants and Variables
  • Variable: A named memory location that can store data which can change during program execution. Declaration: int age;
  • Constant: A value that cannot be changed during program execution. Defined using #define or the const keyword. Examples: #define PI 3.14159 or const int MAX = 100;
5.2.9 Type Specifier

Type specifiers (also called format specifiers) are used in input/output functions to specify the type of data being read or printed. Common specifiers:

  • %d: Integer (int)
  • %f: Float
  • %lf: Double
  • %c: Character
  • %s: String (character array)
  • %x: Hexadecimal
  • %o: Octal
5.2.10 Simple and Compound Statements
  • Simple Statement: A single statement ending with a semicolon. Example: a = 10;
  • Compound Statement: A group of statements enclosed within curly braces { }. It is treated as a single logical unit. Example: { a = 10; b = 20; c = a + b; }
5.2.11 Operators and Expressions: arithmetic, relational, logical, assignment, unary and conditional operators
  • Arithmetic Operators: + (addition), - (subtraction), * (multiplication), / (division), % (modulus).
  • Relational Operators: == (equal to), != (not equal), < (less than), > (greater than), <= (less than or equal), >= (greater than or equal).
  • Logical Operators: && (AND), || (OR), ! (NOT). Used for combining conditions.
  • Assignment Operator: = (assigns value). Example: x = 10;
  • Unary Operators: ++ (increment), -- (decrement), - (negative).
  • Conditional Operator (Ternary): ? : - A shorthand for if-else. Syntax: condition ? expression1 : expression2;
5.2.12 Input/output (I/O) Functions
  • Input Functions: scanf() is used to read formatted input from the keyboard. getch(), getchar(), gets() are also used for input.
  • Output Functions: printf() is used to display formatted output. putchar(), puts() are also used.
5.2.13 Selection Control Statement: Decisions (if, if-else, if-else-if, nested and, switch)
  • if: Executes a block of code if a condition is true. Syntax: if(condition) { // statements }
  • if-else: Executes one block if condition is true, another if false. Syntax: if(condition) { } else { }
  • if-else-if (Ladder): Used for multiple conditions. Syntax: if(cond1) { } else if(cond2) { } else { }
  • Nested if: An if statement inside another if statement.
  • switch: A selection statement that checks a variable against multiple cases. Syntax: switch(variable) { case value1: // statements; break; default: // statements; }
5.2.14 Iteration Control Statement: Looping (while, do while, for nested)
  • while: Executes a block of code while a condition is true. Condition is checked before execution. Syntax: while(condition) { // statements }
  • do-while: Executes the block first, then checks the condition. Guarantees at least one execution. Syntax: do { // statements } while(condition);
  • for: A compact loop with initialization, condition, and increment/decrement in one line. Syntax: for(init; condition; increment) { // statements }
  • Nested Loop: A loop inside another loop.
5.2.15 Array: definition, types(1D and 2D), matrix addition and subtraction

An array is a collection of similar data types stored in contiguous memory locations and accessed using an index.

  • 1D Array: A linear array with one row. Declaration: int arr[5];
  • 2D Array: A matrix with rows and columns. Declaration: int matrix[3][3];

Matrix Addition: Two matrices can be added if they have the same dimensions. Corresponding elements are added. Matrix Subtraction: Similar to addition, corresponding elements are subtracted.

5.2.16 String: definition and string function : strlen(), strcat(), strcmp(), strrev(), strcpy(), strlwr(), strupr()

A string is a sequence of characters stored in a character array and terminated by a null character '\0'. Strings are manipulated using functions from the string.h header file.

  • strlen(str): Returns the length of the string (excluding the null character).
  • strcat(str1, str2): Appends str2 to the end of str1.
  • strcmp(str1, str2): Compares two strings. Returns 0 if equal, positive if str1 > str2, negative if str1 < str2.
  • strrev(str): Reverses the string.
  • strcpy(dest, src): Copies src string to dest.
  • strlwr(str): Converts a string to lowercase.
  • strupr(str): Converts a string to uppercase.
