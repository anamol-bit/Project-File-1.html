Chapter 3: Computer Software and Operating System (12 Hour)

3.1 Concept of Software

Software is a collection of programs, data, and instructions that tell a computer how to perform specific tasks. It is the intangible component of a computer system, as opposed to the physical hardware.

3.1.1 Definition of software

Software is a set of instructions, data, or programs used to operate computers and execute specific tasks. It is the non-tangible part of a computer system that enables the hardware to function and perform useful work. Without software, a computer is just a collection of electronic components.

3.1.2 Categories of software: System, Utility, Application, Web Based, Mobile Apps

Software can be broadly categorized into several types based on their purpose and usage:

  • System Software: This includes the operating system and other software that manage computer hardware and provide a platform for running application software. Examples: Windows, Linux, macOS.
  • Utility Software: These are system software that help maintain, analyze, and optimize the computer. Examples: antivirus, disk cleanup, backup software, file compression tools.
  • Application Software: These are programs designed to perform specific tasks for users. Examples: Microsoft Word, Excel, Photoshop, web browsers.
  • Web Based Software: These are applications that run in a web browser and do not require installation on the local computer. They are accessed over the internet. Examples: Google Docs, Gmail, online banking portals.
  • Mobile Apps: These are software applications designed specifically for mobile devices like smartphones and tablets. They are typically downloaded from app stores. Examples: WhatsApp, Instagram, Uber, mobile games.
3.2 Concept of Operating System

An operating system (OS) is the most important system software that manages all hardware and software resources of a computer. It acts as a bridge between the user and the hardware.

3.2.1 Introduction to Operating System

An Operating System is a software that manages computer hardware and software resources and provides common services for computer programs. It is the foundation upon which all other software runs. Examples include Microsoft Windows, Apple macOS, Linux, Android, and iOS.

3.2.2 Role of Operating System

The primary role of an operating system is to act as an intermediary between the user and the computer hardware. It provides a user-friendly environment where users can run applications, manage files, and control hardware devices. It also ensures that different programs can run simultaneously without interfering with each other.

3.2.3 Functions of an Operating System

The main functions of an operating system include:

  • Process Management: Loading, executing, and terminating programs; managing CPU time scheduling.
  • Memory Management: Allocating and deallocating memory to running programs and ensuring efficient use of RAM.
  • File Management: Creating, deleting, reading, writing, and organizing files on storage devices.
  • Device Management: Controlling and communicating with input/output devices like keyboards, monitors, printers, and storage drives through device drivers.
  • Security and Access Control: Managing user authentication, permissions, and protecting the system from unauthorized access.
  • User Interface: Providing a way for users to interact with the computer, either through Command-Line Interface (CLI) or Graphical User Interface (GUI).
  • Error Detection and Handling: Detecting and responding to hardware and software errors to maintain system stability.
3.2.4 Operating system terminology: multiprogramming, multitasking, multiprocessing and distributed
  • Multiprogramming: The ability of an OS to keep multiple programs in memory simultaneously and switch between them efficiently to keep the CPU busy. It increases CPU utilization.
  • Multitasking: Similar to multiprogramming, but on a more user-interactive level. It allows a user to run multiple applications at the same time (e.g., listening to music while typing a document).
  • Multiprocessing: The use of two or more CPUs (processors) within a single computer system to execute multiple tasks simultaneously, improving overall performance.
  • Distributed Operating System: An OS that manages a group of independent computers and makes them appear as a single coherent system. Resources and tasks are shared across multiple connected machines over a network.
3.3 Windows Operating System

Microsoft Windows is one of the most widely used operating systems in the world. It is a GUI-based system designed for personal computers, laptops, and enterprise environments.

3.3.1 Introduction to GUI based Operating system and its features

A Graphical User Interface (GUI) based operating system allows users to interact with the computer using visual elements like windows, icons, menus, and pointers (mouse). Key features of GUI-based OS (like Windows) include:

  • Visual desktop environment with icons and taskbar.
  • Point-and-click functionality using a mouse.
  • Multitasking with multiple windows open simultaneously.
  • Drag-and-drop file management.
  • Customizable interface (themes, backgrounds, screen resolution).
  • Easy access to settings and system controls through menus.
3.3.2 Working in Desktop Application and Window Environment

The desktop is the main screen you see after logging into Windows. It contains the taskbar (with Start button, system tray, and pinned applications), desktop icons (shortcuts to programs/folders), and the background wallpaper. Windows environment allows you to:

  • Open, close, minimize, maximize, and resize application windows.
  • Switch between running applications using Alt+Tab or the taskbar.
  • Work with multiple applications side-by-side using snap feature.
  • Access the Start Menu to launch programs, search for files, and access system settings.
3.3.3 Manage Files and Folders with File Explorer

File Explorer (formerly Windows Explorer) is the tool for managing files and folders in Windows. It allows you to:

  • Navigate: Browse through drives, folders, and files using the navigation pane.
  • Create: Create new folders to organize your files.
  • Copy, Move, Delete: Manage files using copy-paste, cut-paste, or drag-and-drop; delete unwanted files (to Recycle Bin).
  • Rename: Change the name of files and folders.
  • Search: Find files and folders by name or content using the search bar.
  • View Options: Change how files are displayed (details, icons, list, etc.) and sort them by name, date modified, type, or size.
3.3.4 Customize the start menu and desktop
  • Start Menu Customization: You can pin/unpin apps, resize the menu, organize tiles into groups, and change the layout. Right-click on any app to pin it to Start or the taskbar.
  • Desktop Customization: Right-click on the desktop to access personalization options. You can:
    • Change the desktop background (wallpaper) to a picture, solid color, or slideshow.
    • Apply different themes that change colors, sounds, and mouse pointers.
    • Add/remove desktop icons (like This PC, Recycle Bin, Network).
    • Adjust screen resolution and display scaling.
3.3.5 Installing and removing devices
  • Installing Devices: Most devices (printers, USB drives, external hard disks) are Plug-and-Play, meaning Windows automatically detects and installs necessary drivers when connected. For some devices, you may need to manually install drivers from a CD or download from the manufacturer's website.
  • Removing Devices: For safe removal of USB devices, use the "Safely Remove Hardware" icon in the system tray to avoid data corruption. To uninstall a device (like a printer or sound card), you can remove its drivers from Device Manager or use the manufacturer's uninstaller.
3.3.6 Manage passwords and privacy levels
  • Passwords: Windows allows you to set a local password, PIN, picture password, or use Windows Hello (fingerprint/face recognition). To change, go to Settings > Accounts > Sign-in options.
  • Privacy Levels: You can control which apps have access to your camera, microphone, location, contacts, and other sensitive data. Go to Settings > Privacy & Security to manage these permissions.
3.3.7 Use of control panel, system tools and accessories
  • Control Panel: (Classic tool) Provides access to system settings like hardware, network, user accounts, and programs. Key sections include:
    • System and Security (firewall, backup, system info).
    • Network and Internet.
    • Hardware and Sound (devices, printers).
    • Programs (uninstall software, turn Windows features on/off).
    • User Accounts.
  • System Tools:
    • Task Manager: View running processes, monitor performance, and end unresponsive applications (Ctrl+Shift+Esc).
    • Disk Cleanup: Remove temporary files to free up space.
    • Defragment and Optimize Drives: Organize files on hard disks for better performance.
    • System Restore: Restore system files and settings to an earlier point.
    • Device Manager: View and manage hardware devices and their drivers.
  • Accessories: Built-in applications provided with Windows, including:
    • Notepad: A simple text editor.
    • WordPad: A basic word processor.
    • Paint: A simple drawing application.
    • Calculator: For arithmetic and scientific calculations.
    • Snipping Tool / Snip & Sketch: For capturing screenshots.
    • Command Prompt: Text-based command-line interface for advanced tasks.
3.4 Open sources and Mobile Operating System

While Windows is proprietary, there are other operating systems that are open-source and others designed specifically for mobile devices.

3.4.1 Concept of Open Sources Operating System

An open-source operating system is one whose source code is freely available to the public. Anyone can view, modify, and distribute the code under specific licenses (like GPL). This promotes collaboration, transparency, and customization. Open-source OSs are often free of cost and have large community support.

3.4.2 Introduction to Linux and UNIX
  • UNIX: A powerful, multi-user, multitasking operating system developed in the 1960s at Bell Labs. It is the foundation for many modern operating systems, including Linux and macOS. It is known for its stability, security, and command-line environment.
  • Linux: A Unix-like, open-source operating system kernel created by Linus Torvalds in 1991. It is widely used on servers, supercomputers, and embedded systems. Linux is free, highly customizable, and has a large community of developers.
3.4.3 Linux Distributions

A Linux distribution (or distro) is a complete operating system package that includes the Linux kernel, system libraries, utilities, and applications. Different distributions are tailored for different purposes. Common Linux distributions include:

  • Ubuntu: One of the most popular user-friendly distros for desktops and laptops.
  • Debian: Known for its stability and is the foundation for many other distros.
  • Fedora: A cutting-edge distro with the latest software features.
  • Linux Mint: Designed for ease of use, good for beginners.
  • CentOS / RHEL: Used primarily in enterprise and server environments.
  • Arch Linux: For advanced users who want complete control over their system.
3.4.4 Concept of Mobile Operating System

A Mobile Operating System (Mobile OS) is software designed to run on mobile devices like smartphones, tablets, and smartwatches. It manages hardware resources and provides a platform for mobile applications. Key features include touch-based interface, battery management, cellular connectivity, GPS, and integration with app stores.

3.4.5 Types of Mobile Operating System

The major mobile operating systems are:

  • Android: Developed by Google, based on the Linux kernel. It is the most widely used mobile OS globally, open-source (AOSP), and used by many manufacturers (Samsung, Xiaomi, OnePlus, etc.).
  • iOS: Developed by Apple exclusively for iPhones and iPads. It is a closed-source, highly secure and optimized OS known for its smooth user experience and ecosystem integration.
  • HarmonyOS: Developed by Huawei, a distributed OS designed for multiple device types including smartphones, tablets, and smart devices.
  • KaiOS: A lightweight mobile OS for feature phones and entry-level smartphones, popular in developing markets.
