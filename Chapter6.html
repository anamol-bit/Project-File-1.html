Chapter 6: Web Technology I (8 hour)

6.1 Introduction: web development Introduction

Web development is the process of creating websites and web applications. It involves designing, building, and maintaining the front-end (what users see) and back-end (server-side logic) of a website. The web is built on technologies like HTML, CSS, JavaScript, and various server-side languages. Web development can be broadly classified into front-end development, back-end development, and full-stack development.

6.2 Web browsers and search Engines
  • Web Browser: A software application used to access, retrieve, and view content on the World Wide Web. Examples include Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, and Opera. Browsers interpret HTML, CSS, and JavaScript to display web pages.
  • Search Engine: A web-based tool that helps users find information on the internet by searching through indexed web pages. Examples include Google, Bing, Yahoo, and DuckDuckGo. Search engines use algorithms to rank results based on relevance.
6.3 Overview of various Internet & web technologies

Internet and web technologies include the following:

  • HTTP/HTTPS: Hypertext Transfer Protocol (Secure) - protocol for transferring web pages.
  • URL: Uniform Resource Locator - the address of a web page.
  • HTML: HyperText Markup Language - used to structure web content.
  • CSS: Cascading Style Sheets - used to style web pages.
  • JavaScript: A scripting language that adds interactivity to web pages.
  • Web Servers: Software/hardware that hosts websites (Apache, Nginx, IIS).
  • Web Hosting: Service that provides storage space for websites.
  • DNS: Domain Name System - translates domain names to IP addresses.
6.4 Content Management System (CMS)

A Content Management System (CMS) is a software application that allows users to create, manage, and modify digital content without needing technical knowledge of web programming. CMS platforms provide a user-friendly interface for adding text, images, videos, and managing website structure.

Popular CMS examples include WordPress, Joomla, Drupal, and Shopify. Features include:

  • WYSIWYG (What You See Is What You Get) editors.
  • Template-based design.
  • User and permission management.
  • Search engine optimization (SEO) tools.
  • Plugins and extensions for added functionality.
6.4 HTML: The Language of the web

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It uses tags to define elements like headings, paragraphs, links, images, and tables. HTML is the foundation of all web pages.

6.4.1 Objectives

The objectives of HTML include:

  • To structure web content in a logical and organized manner.
  • To create hyperlinks that connect different web resources.
  • To embed multimedia elements like images, audio, and video.
  • To enable the creation of interactive web forms.
  • To provide a foundation for CSS and JavaScript to enhance web pages.
6.4.2 Structure of HTML

An HTML document has a standard structure:

    <!DOCTYPE html>
    <html>
      <head>
        <title>Page Title</title>
      </head>
      <body>
        <h1>Heading</h1>
        <p>This is a paragraph.</p>
      </body>
    </html>
6.4.3 Published and Hosting

Published: To make a website available to the public, the HTML files must be published (uploaded) to a web server.

Web Hosting: A service that provides storage space on a server for websites, making them accessible on the internet. Types include shared hosting, VPS, dedicated hosting, and cloud hosting.

6.4.4 HTML Tags vs. Attributes
  • Tag: The basic building block of HTML. Tags are enclosed in angle brackets < >. Most tags have an opening <tag> and closing </tag>. Example: <p> and </p>.
  • Attribute: Additional information about an HTML element. Attributes are added to the opening tag. They provide properties like color, size, alignment, and links. Syntax: <tag attribute="value">. Example: <img src="image.jpg" alt="description">.
6.4.5 Basic Tags of HTML: HTML, HEAD, TITLE, BODY (Setting the Fore color and Background color, Background Image, Background Sound)
  • <html>: The root element that wraps the entire HTML document.
  • <head>: Contains metadata, title, and links to stylesheets/scripts. Not visible on the page.
  • <title>: Sets the title that appears on the browser tab.
  • <body>: Contains the visible content of the web page.
    • Fore color: Set using text="color" in the body tag. Example: <body text="red">.
    • Background color: Set using bgcolor="color". Example: <body bgcolor="blue">.
    • Background Image: Set using background="image.jpg". Example: <body background="bg.jpg">.
    • Background Sound: Set using <bgsound src="sound.wav"> (old tag, not HTML5).
6.4.6 Heading tag (H1 to H6) and attributes(ALIGN)

The heading tags (<h1> to <h6>) define headings. H1 is the largest/most important, and H6 is the smallest.

  • ALIGN attribute: Sets the alignment of the heading. Values: left (default), center, right, justify. Example: <h1 align="center">Centered Heading</h1>.
6.4.7 FONT tag and Attributes (Size: 1 to 7 levels, BASEFONT, SMALL, BIG, COLOR)

The <font> tag is used to control the appearance of text (deprecated in HTML5, but still used in older pages).

  • Size: Values 1 (smallest) to 7 (largest). Example: <font size="5">Text</font>.
  • BASEFONT: Sets the default font size for the page.
  • SMALL: Reduces the font size. <small>text</small>.
  • BIG: Increases the font size. <big>text</big>.
  • COLOR: Sets the text color. Example: <font color="red">Text</font>.
6.4.8 Paragraph Formatting (P)

The <p> tag defines a paragraph. It adds vertical space before and after the text.

6.4.9 Break Line BR

The <br> tag inserts a line break (carriage return). It is a self-closing tag.

6.4.10 Comment In HTML

Comments are ignored by the browser and are used to explain code. Syntax: <!-- This is a comment -->

6.4.11 Formatting text (B, I, U, Mark, Sup, Sub, EM, BLOCKQUOTE, PREFORMATTED)
  • <b>: Bold text.
  • <i>: Italic text.
  • <u>: Underlined text.
  • <mark>: Highlighted text (background color).
  • <sup>: Superscript (e.g., x2).
  • <sub>: Subscript (e.g., H2O).
  • <em>: Emphasized text (usually italic).
  • <blockquote>: Indented block of text, often used for quotations.
  • <pre>: Preformatted text, preserves spaces and line breaks.
6.4.12 Ordered List - OL (START, Type: 1, I, A, a; START, VALUE)
  • <ol>: Creates an ordered (numbered) list. Items are defined with <li>.
  • START: Specifies the starting number. Example: <ol start="5">.
  • TYPE: Specifies the numbering style.
    • 1: Numbers (1, 2, 3...).
    • I: Roman numerals (I, II, III...).
    • i: Roman numerals (i, ii, iii...).
    • A: Uppercase letters (A, B, C...).
    • a: Lowercase letters (a, b, c...).
  • VALUE: Sets the number for a specific <li> item.
6.4.13 Unordered List - UL (Bullet Type: Disc, Circle, Square, DL, DT, DD)
  • <ul>: Creates an unordered (bulleted) list. Items are defined with <li>.
  • Bullet Type:
    • Disc: Filled circle (default).
    • Circle: Hollow circle.
    • Square: Solid square.
  • <dl>: Definition list (description list). Contains <dt> (term) and <dd> (definition/description).
6.4.14 ADDRESS Tag and Creating Links

<address>: Defines contact information (author, address, email). Usually displayed in italics.

Creating Links (Hyperlinks): Use the <a> (anchor) tag.

  • Link to other HTML documents: <a href="page.html">Link Text</a>.
  • Link to places in the same document: Use id attribute and #. Example: <a href="#section1">Go to Section 1</a>.
  • Link to places in other HTML documents: <a href="other.html#section2">Link Text</a>.
  • Anchor Tag and Hyperlink: <a href="url">text</a>. Common attributes: href (destination), target (_blank, _self, _parent, _top).
6.4.15 Tables: Creating Tables using TR, TH and TD Tags

Tables are used to display data in rows and columns.

  • <table>: Defines the table.
  • <tr>: Defines a table row.
  • <th>: Defines a table header cell (bold and centered).
  • <td>: Defines a standard table data cell.
  • Attributes: border, cellpadding, cellspacing, width, align, valign, colspan, rowspan.
6.4.16 Forms: Creating form using Textbox, radio, checkbox, text area, Button

Forms are used to collect user input. The <form> tag defines a form. Common input types:

  • Textbox: <input type="text" name="name">
  • Radio Button: <input type="radio" name="gender" value="male">
  • Checkbox: <input type="checkbox" name="hobby" value="reading">
  • Text Area: <textarea rows="4" cols="50"></textarea>
  • Button: <input type="button" value="Click Me"> or <button>Click Me</button>
  • Submit Button: <input type="submit" value="Submit">
6.4.17 Introduction to HTML 5 Elements including audio, embed, source, track and video attributes

HTML5 introduced new multimedia elements that allow embedding audio and video directly without plugins.

  • <audio>: Embeds audio files. Example: <audio controls><source src="audio.mp3" type="audio/mp3"></audio>.
  • <video>: Embeds video files. Example: <video controls><source src="video.mp4" type="video/mp4"></video>.
  • <embed>: Embeds external content (like PDF, SWF). Example: <embed src="file.pdf" type="application/pdf">.
  • <source>: Specifies multiple media sources for <audio> or <video>.
  • <track>: Adds captions/subtitles for <video>.
6.4.18 HTML 5 Graphics using canvas and svg tags
  • <canvas>: A container for drawing graphics using JavaScript. Used for 2D shapes, animations, and games.
  • <svg>: Scalable Vector Graphics - used for drawing vector-based graphics. SVG elements are defined using XML. Examples: <circle>, <rect>, <line>.
6.4.19 Concept of domain name and web hosting
  • Domain Name: A human-readable address for a website (e.g., google.com). It is translated to an IP address by DNS. Domain names have extensions like .com, .org, .net, .np (country-specific).
  • Web Hosting: A service that provides storage space and resources for websites to be accessible on the internet. The domain name points to the hosting server.
6.5 Cascading Style Sheets 6.5.1 Introduction to Cascading Style Sheet (CSS)

CSS (Cascading Style Sheets) is a stylesheet language used to control the visual presentation of HTML documents. It allows developers to separate content (HTML) from presentation (styling). CSS controls layout, colors, fonts, spacing, and responsive design.

6.5.2 Inline CSS

Inline CSS is applied directly to an HTML element using the style attribute. It affects only that specific element. Example: <p style="color: red; font-size: 20px;">This is red text.</p>. Inline CSS has the highest priority.

6.5.3 Embedded CSS (Internal CSS)

Embedded CSS is defined within the <head> section of an HTML document using the <style> tag. It applies to the entire page. Example:

    <style>
      p { color: blue; font-size: 16px; }
    </style>
6.5.4 External CSS

External CSS is defined in a separate .css file and linked to the HTML document using the <link> tag. This allows the same styles to be applied to multiple pages. Example: <link rel="stylesheet" href="styles.css">. External CSS is the preferred method for large websites.
